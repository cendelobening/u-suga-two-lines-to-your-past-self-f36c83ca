Two lines to a past self, written as a warning and a lesson. The first line names one exact moment — a term sheet signed at 11:40 pm on March 14 in a hotel lobby, with a single-vote replacement clause hiding on page nine — because a warning only works when the moment is concrete enough to recognize. The second line traces the cost straight to the change: that signature lost the company, and now every page gets read twice and nothing gets signed after midnight.

## Run it

```sh
python3 main.py
```

This writes the two lines to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline, and verifies the output on read-back.
